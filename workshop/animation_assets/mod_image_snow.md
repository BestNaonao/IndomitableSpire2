# 塔什干动态雪花封面

成品：`TashkentSpire2/mod_image_snow.png`。沿用项目现有文件名，文件内容实际为动画 WebP。原 `mod_image.png` 保留不变，`project.godot` 的静态图标引用也未修改。

## 最终规格

- 420×420 像素，5,000ms 无限循环。
- 275 个不同的画面，平均 55 FPS；帧时长为 18ms、19ms，没有重复帧凑帧率。
- 995,094 字节，约 995KB / 972KiB，严格小于 1,000,000 字节。
- 原画使用内置 imagegen 优化冷紫蓝背景和人物对比度，见 [完整提示词](tashkent_snow_prompt.md)；生成底图为 `tashkent_snow_base.png`。
- 静态底图只做一次 Q90 有损 WebP 编码，随后雪花采用无损增量帧，避免背景反复量化导致跳色。容器实际包含 1 帧 VP8 和 274 帧 VP8L；整张动画相对生成底图仍是有损图像，并非未经压缩的原画。
- 26 片雪花分三层：远景直径约 1.8–3px、中景约 6–10px、前景约 18–24px。大雪片分布在不同横向区域，避免集中在白色衣服上或被边缘裁切。
- 雪片使用略不规则的分枝轮廓和柔和实心中心，带下落、左右飘摆、轻微转动及侧翻变薄；只对粒子内部做约 0.32px 柔化，不模糊人物底图。面部区域减弱遮挡。
- 循环边界使用柔和的透明度过渡，轨迹、翻转角度及透明度在周期两端完全一致。

## 实测取舍

| 方案 | 周期 / 帧率 | 文件大小 | 结果 |
| --- | --- | ---: | --- |
| 旧版小粒子，32 片 | 5s / 90FPS | 941,330 B | 原版本，雪花较小 |
| 本次大雪片，26 片 | 5s / 48FPS | 894,362 B | 合格 |
| 本次大雪片，26 片 | 5s / 54FPS | 981,084 B | 合格 |
| 本次大雪片，26 片 | 5s / 55FPS | 995,094 B | 最终版本 |

大雪片和柔化会增加增量帧体积，因此从旧版 90FPS 调整至 55FPS，在本次最终造型的已测试方案中保留符合 1MB 限制的较高帧率。帧时长为 18–19ms。

## 重建与校验

依赖 Pillow 12.3.0（libwebp 1.6.0）和 NumPy 2.3.5。项目根目录运行：

```powershell
python workshop/build_mod_image_snow.py
python workshop/build_mod_image_snow.py --validate-existing TashkentSpire2/mod_image_snow.png
```

默认参数就是最终版本：`--fps 55 --duration 5 --particles 26 --quality 90 --method 4 --stable-lossy`。

校验包含：尺寸、总时长、无限循环、275 帧唯一性、实际 VP8/VP8L 帧类型、文件体积、源轨迹周期端点一致，以及所有解码帧与“已量化底图＋对应雪花”逐像素一致。最终规格明细保存于 `mod_image_snow.metrics.json`。
