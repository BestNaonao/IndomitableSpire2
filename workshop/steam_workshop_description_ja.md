# AZUR LANE: TASHKENT MOD / アズールレーン タシュケントMOD

『アズールレーン』の北方連合所属駆逐艦「タシュケント」が尖塔に参戦。弾薬を装填し、距離を調整し、優先目標を標的に定め、最適なタイミングで魚雷を命中させましょう。

このMODを使用するには、**BaseLib 3.4.5以降**が必要です。

![Mod Content](https://raw.githubusercontent.com/BestNaonao/IndomitableSpire2/branch_tashkent/workshop/images/tashkent_workshop_content.png)

## MOD CONTENT / MOD内容

- 新プレイアブルキャラクター **1名**：タシュケント
- 新カード **91＋14枚**
- 新レリック **6＋10個**
- 新ポーション **3個**
- 新たな古の存在 **1名**：ソビエツキー・ソユーズ
- 選択可能な衣装 **4種類**。それぞれに戦闘、商人、休憩所用の専用Spineモデルを収録

## CORE MECHANICS / コアメカニズム

### AMMO & LOAD / 弾薬と装填

弾薬カードには、現在の弾薬数と弾薬上限が表示されます。**装填（Load）**すると、そのカードの弾薬が増加します。弾薬は戦闘終了後も保持されるため、ルート選択や長期的なリソース管理が重要になります。

### FIRE & FOCUS FIRE / 発射と集中砲火

戦闘中、弾薬を1つ消費するたびに、そのカードの**発射（Fire）**以降に記載された効果が1回発動します。

**集中砲火X（Focus Fire X）**を持つカードは、X以上の弾薬を消費することで追加効果を発動します。

### TORPEDO / 魚雷

魚雷は将来のターン終了時に、**標的**が最も多い敵へ自動的に命中します。ダメージは対象の標的によって増加し、命中までの時間は魚雷を発射した時点の距離によって決まります。

- 距離 **4～5**：現在のターン終了時に命中
- 距離 **2～3**：次のターン終了時に命中
- その他の距離：2ターン後の終了時に命中

### DISTANCE / 距離

距離は敵との相対的な位置を表し、範囲は **-5～5** です。正の距離が1増えるごとに、与えるダメージが **20%**、受けるダメージが **10%** 増加します。負の距離では、与えるダメージと受けるダメージの両方が減少します。

距離は魚雷が標的に到達するまでの時間にも影響します。突撃して高火力と素早い命中を狙うか、後退して安全に戦うかを選択できます。

### MARK / 標的

標的は、攻撃ダメージを受けた時に発動するデバフです。対象は攻撃を受けるたびに現在の標的の層数と同じ追加ダメージを受け、その後、標的を1層失います。魚雷のダメージも対象の標的によるボーナスを受けます。

## EXTRA FEATURES / 追加機能

- キャラクター選択画面から、**4種類のタシュケント衣装**を切り替えられます。
- マルチプレイの指差し・じゃんけんモデルでは、通常の「手モデル」に加えて「脚モデル」も選択できます。
- 距離メカニズムは第2幕ボスの**サンドワーム**と連動します。突撃すると砂地獄のカウントが減少し、サンドワームに引き込まれる動きもダメージ上昇へ変換できます。後退時は逆方向に作用します。
- 距離メカニズムは第2幕ボスの**エンペラークラブ**とも連動します。左へ突撃すると右側の敵からは後退した扱いになり、その逆も同様です。
- オリジナルの無色カード**「爆弾（The Bomb）」**は魚雷へ変換され、タシュケントの魚雷関連ボーナスが適用されます。
- 魚雷、海王形態、ワープドライブなどの能力には専用の戦闘エフェクトがあります。
- 簡体字中国語、英語、日本語、韓国語に対応しています。
