# AZUR LANE: TASHKENT MOD / 碧蓝航线塔什干模组

让来自《碧蓝航线》的北方联合驱逐舰塔什干加入尖塔。装填弹药、调整距离、锁定标记目标，并让预先布置的鱼雷在最合适的时机命中敌人。

本模组需要前置模组 【BaseLib 3.4.5 或更高版本】。

![Mod Content](https://raw.githubusercontent.com/BestNaonao/IndomitableSpire2/branch_tashkent/workshop/images/tashkent_workshop_content.png)

- 【91 + 14】 张新卡牌

## CORE MECHANICS / 核心机制

### AMMO & LOAD / 弹药与装填

带有弹药的卡牌拥有“当前弹药 / 弹药上限”。【装填（Load）】会增加该卡的弹药数量；弹药可以跨战斗保留，因此路线规划与长期资源分配同样重要。

### FIRE & FOCUS FIRE / 发射与集火

战斗中，每消耗 1 份弹药，就会执行一次卡牌中位于【发射（Fire）】后的效果。

打出带有【集火 X（Focus Fire X）】的卡牌时，如果选择消耗的弹药数量不低于 X，就会触发对应的额外效果。

### TORPEDO / 鱼雷

鱼雷会在未来的回合结束时自动命中【标记最高】的敌人，并获得目标标记层数带来的伤害加成。命中时间由释放鱼雷时的距离决定：

- 距离 【4～5】：本回合结束时命中
- 距离 【2～3】：下一回合结束时命中
- 其他距离：下两回合结束时命中

### DISTANCE / 距离

距离表示你与敌人的相对位置，范围为 【-5～5】。每提高 1 点距离，造成的伤害提高 【20%】，受到的伤害提高 【10%】；降低距离则会同时降低输出与承伤。

距离还会决定鱼雷抵达目标所需的时间。积极突进可以换取爆发与快速命中，主动后撤则能获得更安全的战斗节奏。

### MARK / 标记

标记是一种会在受到攻击伤害时触发的负面状态。目标每受到一次攻击，会额外受到等同于当前标记层数的伤害，然后移除 1 层标记；鱼雷伤害同样会受到目标标记层数加成。

## EXTRA FEATURES / 额外功能

- 可在角色选择界面切换 【4 套塔什干装束】。
- 多人模式的指向与猜拳模型可选择“手部模型”或“腿部模型”。
- 距离机制会与二层 Boss 【沙虫】联动：突进会减少沙坑计数，被拖入沙坑时也能转化为伤害优势；后撤时则反向结算。
- 距离机制会与二层 Boss 【帝王蟹】联动：朝左突进等同于对右侧敌人后撤，反之亦然。
- 原版无色卡牌【炸弹（The Bomb）】的机制会替换为鱼雷，并适用塔什干体系中的鱼雷加值。
- 鱼雷、海王形态与曲速驱动等能力拥有专属战斗特效。
- 支持简体中文、English、日本語与한국어。
