# 蓄力打击：专用骨骼下蹲（2026-11-07）

## 实现

四个现有 `.skel` 各追加一段 `tashkent_charge_crouch`，仍使用原 atlas 和贴图。没有缩放整张模型，也没有通过 `sit` 隐藏舰装／更换表情。骨盆（第三套命名为 `bone`）以 smoothstep 在 0.2 秒内下降：原皮 17、其余三套 18 个 Spine 单位，同时前倾 4°；大腿／小腿独立转动，保持从原生运行时 `normal / 0` 测得的脚端坐标，头部和躯干的缩放完全不变。

作者工具 `tools/append_charge_crouch.mjs` 读取原始二进制里的完整精度骨骼数据，根据两连杆逆运动学求屈膝角度，再烘焙为 49 个平滑位移／旋转采样及末端保护帧。不在运行时开启 IK mix，避免第四套攻击不含 IK 时间轴而留下约束状态；新片段不含 scale、shear、slot、deform、draw-order、action／finish 事件或物理时间轴。

生成工具不进行 JSON→二进制整骨架重导出：保留整个旧文件所有字节，只把动画数量 20 改成 21，再尾部追加 3,071 字节。四皮肤共增加 12,284 字节，不增加纹理、节点或粒子。工具核对原始 SHA-256 与动画数量位置、逐字节回验既有数据，并能识别自己的精确输出，因此重复运行不会无限追加。若源骨架变动则拒绝运行，要求重新测量脚位。

本地四个 `.skel.import` 的目标是原样二进制 `.spskel`，没有重新序列化资源外壳。对应 `.godot/imported` 缓存已同步为新二进制，并更新 source／dest MD5，防止未重新导入就打包时遗漏新动作；原始 `.import` 路径和 UID 不变。更换源数据后的其他工作副本仍需正常重新导入资源。

```text
node tools/append_charge_crouch.mjs INPUT_DIRECTORY OUTPUT_DIRECTORY
```

## 播放与中断

`NCloseStrikeVfx` 在原 `attack` 的预备姿态上叠加专用 track 1，只控制所需的下半身、骨盆与躯干骨骼，不改变手臂、头发、表情、贴图或原始模型变换。片段的实际结尾放在 0.21 秒，蓄势只采样到 0.2 秒并单独暂停此 entry，避免把附加片段的 completed 信号误当成原攻击完成。基础轨道仍是官方 `Attack`。

总蓄势 0.68 秒、冲刺 0.16 秒、命中对齐 `attack / 0.2`、回位逻辑及 Fast 补偿不变。蓄势时不再给整个 Body 施加水平／竖直偏移，双脚不会随前倾滑动。冲刺期间逐渐站起并交回原攻击。命中、重播、新动作、死亡、结束与退出立即清理自己的轨道，不通过排队空动画等待暂停轨道走完；track 1 已被其他效果占用时跳过下蹲，不抢占、不回退到模型压缩。
