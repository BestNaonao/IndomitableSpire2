# 蓄力打击 / 致命一击近身演出

两张牌通过 `NCloseStrikeVfx.Attach` 接入同一套纯视觉近身控制器。

- 蓄力打击：稍明显的后撤蓄势，快速贴近指定敌人，停留重击，然后回位。
- 致命一击：更短的蓄势，保持干脆的单次重击。
- 沿用角色原有 `Attack` → Spine `attack` 动作；四套皮肤都有 0.2 秒的 `action` 关键点。实际伤害回调将当前攻击轨道对齐到这一帧，不新增手绘拳击动作，也不修改 Spine 文件。
- 原版 `vfx_heavy_blunt` 改为敌人中心生成。模型停留覆盖原版特效约 0.2 秒的预备阶段；回位只在视觉帧中进行，不 await、不冻结全局时间。
- 两张牌均以 400 世界单位/秒匀速撤回，不影响普通距离后撤的移动速度，不再使用固定时长的缓动或回程跳跃。路程越远，撤回越久；不随卡牌或快速模式压缩回程时间。回程播放现有 `move_left`，自然到达后才恢复待机。
- 命中后监听 Spine 的新动作开始信号：攻击、受击、施法、胜利或另一段移动均可立即接管，包括重新播放同名动作。被打断时立即清除旧偏移，不覆盖新动作；清理与退订同步完成，没有延迟待机回调。

## 结算与兼容

保持原有伤害、伤害结果统计、蓄力打击的活力，以及致命一击的标记 / 保留 / 消耗。保留 `FromCard` 的攻击动画、音效与等待时间；普通 / 快速模式仅调整视觉突进速度，即时模式在伤害回调直接到达接触点。

仅移动角色 `Body` 的附加偏移，不修改 `NCreature`、血条、意图、碰撞范围、距离层数、怪物位置、RNG 或网络消息。各客户端从相同攻击结算回调启动本地演出，无本机玩家过滤。没有 Spine 时仍可做模型位移；其他角色获得这两张牌时保持自己的默认演出。

连续重播会先清除旧偏移。目标在命中前失效、攻击被动作打断、攻击者死亡、模型切换、场景退出、战斗结束都会回收；命中后敌人死亡仍可正常回位。未走到伤害回调时有 1.25 秒的视觉保险回收。清除时只减去本控制器施加的偏移，不覆盖其他布局改动。
