# 海王形态：夜海纯覆盖层（2026-11-08）

## 当前策略

只添加海王自己的展示节点，不替换官方背景根节点、不接管帝皇蟹、不隐藏原风景，也不恢复任何外部节点的状态。原有前景装饰可以保留在夜海上方；其他模组修改的蟹贴图、材质和动画继续由原模组／官方管理。

沿用现有 `star_level_bg_598.png` 和 `poseidon_ink_reveal.gdshader`，水墨展开／反向消退时间仍为 `1.8 / 1.3 ≈ 1.385` 秒。素材和 shader 均未改动，本次是 C# 行为调整。

## 绘制与兼容边界

```text
原背景根节点（不替换、不调层、不隐藏）
├─ Layer_00..NN：已有风景（不修改）
├─ TashkentPoseidonOverlay：本模组新增
│  └─ Seascape：夜海图片＋原有水墨 shader
├─ 帝皇蟹／第三方演员等未知分支（不修改）
└─ Foreground：已有前景（保留）
```

- 控制器在房间下，只有首次需要展示时才创建一只 Node2D 和一张 TextureRect。只移动这只自有 Node2D 的父节点／排序，不重新挂载任何官方演员或风景。
- 按运行时子节点顺序，插在连续 `Layer_00..NN` 风景之后、首个其他节点之前。前景和未知模组分支都视作保护边界；不依赖 `NKaiserCrabBossBackground` 类型、固定的 `KaiserCrab` 路径或原版贴图名称。
- 即使某个 `Layer_XX` 分支内出现 NCreature 或 SpineSprite，也将整个分支视作受保护内容，覆盖层提前到它之前。
- 覆盖层保持普通 CanvasItem 树顺序，不使用 TopLevel 绕过排序。通过自有 Node2D 的完整逆变换抵消背景相机的位移、缩放、旋转和倾斜，仍让夜海等比铺满战斗视口；鼠标穿透。
- 如其他模组降低演员深度，只降低海王自己的层级。高层风景可能留在海面前方，这是有意的保守降级，不通过降低原风景／抬高演员强行覆盖。
- 不写原节点的 Visible、ZIndex、ZAsRelative、TopLevel、Modulate、SelfModulate、Texture、Material、Position、Scale 或 Rotation。也不覆盖官方背景资源路径、不截图复制蟹、不创建第二套 Spine。
- 原景的前景、光效和粒子可能继续显示／运行，属于纯覆盖策略的取舍；不再为“彻底换净原景”隐藏原节点。对于把人物与风景合成在同一张图、或使用独立 CanvasLayer 的第三方背景，无法保证完整换景；没有安全的画布关系时不展示覆盖层，而不是强行盖住演员／UI。

## 生命周期与多人

- 用公开 `CombatManager.CombatSetUp` 事件安装控制器，初始化幂等。移除原 `NCombatRoom._Ready` Harmony 后置补丁，事件类为 `PoseidonFormBackgroundEvents`。这是每个模组生命周期一次的监听，不随每场战斗叠加。
- `PoseidonFormPower.AfterApplied`／`AfterRemoved` 仍立即刷新；每 0.1 秒检查同步后的能力、晚加入节点、背景替换和绘制边界。官方背景尚未创建时自有图片保持隐藏，之后自动接入。
- 任一存活玩家持有正层数海王形态时展示一张共享夜海。多持有者、死亡／复活、移除最后持有者及中途重新获得形态的规则不变；怪物持有不触发，不改能力的加值和次数。
- 不使用玩法 RNG，不发送额外网络消息，不阻塞出牌或伤害结算。
- 战斗结束立即隐藏并释放本模组节点；退出、场景切换时同样清理、退订战斗结束事件。没有“恢复原景”步骤，因为原景从未被修改。
- 背景被另一模组替换时，只把自有覆盖层挂到新背景；旧背景销毁导致自有子节点一起销毁时，可重新创建展示节点，不复活任何原演员。
