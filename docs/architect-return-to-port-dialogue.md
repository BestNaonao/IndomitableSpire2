# 塔什干与建筑师：返回港区（2026-11-08）

## 创作依据与边界

这是模组原创的跨世界对话，不是碧蓝航线官方剧情，也没有把尖塔建筑师改写成指挥官或塞壬。

- 参考原作游戏的自我介绍、主界面及好感台词：第三人称自称、短促的“这样”式停顿、对外不刻意讨好，以及对港区同伴和指挥官的明确感情。[游戏台词及语音整理](https://wiki.biligame.com/blhx/塔什干)。
- 官方日服 2020-02-21 的舰船介绍强调她本性善良、表情常略显不悦；身份为撒丁建造的北方联合驱逐舰，而非因昵称就当成巡洋舰。[官方原推](https://twitter.com/azurlane_staff/status/1230748627762417665)、[保留该官方介绍的转引页面](https://gamewith.jp/azurlane/article/show/188209)。本次原推直接访问被平台拒绝，采用转引交叉核对，不把转引网站写成官方站点。
- 建筑师参考本地原版 `TheArchitect.cs` 和官方中文 `ancients.json`：冷淡、拒绝帮助、将登塔者打回塔底；没有承诺通关即可回港，也没有编造他与碧蓝世界的官方联系。
- 不采用“伏特加、乌拉”堆叠式刻板表达，也不把略显冷淡写成对指挥官毫无牵挂。她的目标是寻找回港方法，而不是来陪指挥官玩建筑师角色扮演。

## 中文台本

### 第一段：询问归路

塔什干：你就是建筑师？塔什干听说，走到尖塔顶端就能见到你。……这样，现在告诉塔什干，回港区的路在哪里？

建筑师：你爬到这里，只为离开？

塔什干：港区有塔什干的同伴，还有同志酱。外面的路都找过了，才来这里问你。不是来参观的哦。

建筑师：我造了这座塔。没答应替你造一条归路。

塔什干：……这样。那就看看，你这里有没有藏着出口。主炮，开火。

（演出：塔什干播放攻击动作，一发短促炮口闪光、喷焰、飞行光点与少量余烟；建筑师受击动作及原版烟尘。纯表现，不产生伤害。）

建筑师：炮火打开不了你想要的门。

塔什干：塔什干知道自己要回到谁身边。你不肯说，塔什干就自己找。

建筑师：那就回塔底去找吧。


### 第二段：再次登顶

建筑师：又是你。塔底还没让你明白？

塔什干：明白了哦。你送塔什干回去的地方，不是港区。塔什干要回到同志酱身边，不是再看一遍你的楼梯。

建筑师：为了一个不在这里的人，重复这些？

塔什干：……不只。港区的大家认识真正的塔什干，还是愿意和塔什干做朋友。这样的地方，当然要回去。

建筑师：你以为执着能改变尖塔？

塔什干：不试试怎么知道？这次可不是问候了。全炮门，开火。

（演出：三发短齐射，间隔约 0.2 秒；每发短飞行约 0.14 秒。台词和按钮不等待演出完成。）

建筑师：还是同一个答案。

塔什干：那塔什干也一样。下次再见，建筑师。……同志酱，等塔什干回来。

## 实现

- 中英日韩四语言、四个皮肤角色 ID 使用相同两段结构，每段 8 句；按钮文案同步本地化。
- 保留 BaseLib 所用的 `r` 结构及原有胜场选段机制：0 胜优先第一段，1 胜优先第二段，之后可进入现有重复池。不新增存档字段或强制改变选段 RNG。
- `TashkentArchitectDialoguePatch` 在原版 `ShowSpeechBubble` 之后监听具体行键，只有本地玩家的塔什干、角色发言、对应开火台词才触发；不依据中文内容匹配，切换语言不改变演出位置。
- 首段 `0-4r.char` 一发，第二段 `1-5r.char` 三发。每个事件实例、每个行键最多成功触发一次；失效场景未成功生成时不会提前占用触发。
- `NTashkentArchitectShotVfx` 只允许在 `VisualOnly` 事件房间中播放，并定位实际 `Architect` 怪物，不误射同场其他敌人。复用已有三张碧蓝航线炮口贴图、原版烟尘命中特效和塔什干攻击音，不新增图片、场景或音频素材。
- 同时最多一个开火控制器、四个 Sprite2D；单段最多三发，末发约 0.6 秒后自清理。不逐帧加载纹理、不生成游戏模型、不调用 DamageCmd、不改 HP、分数、弹药或网络消息。
- 两段结尾均明确配置 `Architect` 出手；不额外调用原版计分攻击，沿用原有 WinRun 流程。
- 快速点击结尾时，在原版 `WinRun` 前停止并释放残留短齐射，避免延迟 Hit 打断建筑师原版收尾动作。换房间、角色节点退出时也会取消。
- 使用现有 Attack 动画映射，静态立绘没有动画器时仍显示炮口特效，不强制恢复 Idle，不覆盖其他动作。
- 未修改苏维埃同盟的其他 96 条四语言文案；未触碰用户已有的 `DistanceIntentPreview.cs` 修改。
