## 素材与制作

原小人来自 `D:/GitClone/AzurLane/data/char/tashigan_idol`，Spine 4.2.43。复制 atlas、PNG，骨架保留 22 个原动作（包括 `dance`／`idol`），只追加无事件的 `tashkent_charge_crouch`，不重导出／量化原骨架。新增偶像动作保留在文件内，本次不改变原有待机轮换规则。

μ 的骨盆为 `bone`，两条腿为 `leg_L1 → leg_L3`、`leg_R1 → leg_R3`，原文件没有 IK 约束。按其自身脚端位置离线求解膝部旋转、骨盆下移 18 单位，保持原有比例；没有对模型整体做压扁，也未增加运行时 IK 求解。

`tools/append_charge_crouch.mjs INPUT OUTPUT tashigan_idol` 可重新生成；不带第三参数时保留原四皮肤工作流。μ 原始 SHA-256：`e62b0cab05b830cc379373debbd219bc9cc2610b43958cb4ccc698027ee924fc`，新增骨架：`ad50f84b9642c5dcbf7844fee4724dab063303c2cef0ef5719f9390c94380027`。原 400,973 字节除动作计数 22→23 外完全一致；新增 3,071 字节。

立绘使用 `painting/tashigan_idol_tex` 的原始 Texture2D 加原 OBJ 网格还原，并非 AI 重画。全量解包的同名 PNG 是裁切 Sprite（2028×1706），不能直接按原 UV 使用；已从本地原 AssetBundle 定向读取完整纹理（2048×1706），消除拼接缺条。离屏合成为透明 PNG 1713×1800，局内仅加载单张图，不运行网格还原。
